# METE CLINIC — лендинг клиники эпиляции и косметологии

Статический адаптивный лендинг: HTML + CSS + vanilla JS, без сборки, фреймворков, бэкенда и аналитики. Контакты, запись, карта и отзывы настраиваются в одном файле, контент — во втором.

## Быстрый запуск

```bash
cd mete-clinic
node serve.js
```

Откройте http://127.0.0.1:4173

Node нужен только для локального просмотра. Скрипт не требует зависимостей (`npm install` не нужен) и раздаёт текущую папку. Порт можно изменить: `node serve.js 8080` или `PORT=8080 node serve.js`.

Открывать `index.html` напрямую через `file://` не рекомендуется: встроенные виджеты Яндекс Карт и отзывов в этом режиме не загружаются.

## Настройка контактов и записи

Всё — в `site-config.js`.

| Поле | Что делает | Текущее значение |
| --- | --- | --- |
| `bookingUrl` | Ссылка Yclients для всех кнопок записи и карточек услуг | `https://n1801245.yclients.ru/company/1599669/personal/menu?o=` |
| `phoneDisplay` | Телефон как он виден на странице | `+7 (922) 399-14-46` |

| `address` | Адрес; также попадает в title карты | `ул. Фармана Салманова, 18, Тюмень` |
| `workingHours` | График работы; при пустом значении строка скрыта | **пусто** |
| `mapProvider` | Подпись под картой: `"yandex"`, `"2gis"` или `""` | `"2gis"` |
| `mapEmbedUrl` | `src` официального iframe-виджета карты | 2ГИС, официальный виджет |

| `twoGisUrl` | Ссылка «Открыть в 2ГИС»; при пустом значении ссылка удаляется | **пусто** — нужна прямая ссылка на карточку |
| `reviewsEmbedUrl` | `src` официального виджета отзывов | Виджет организации |
| `reviewsUrl` | Ссылка «Все отзывы на Яндекс Картах» | Карточка организации |
| `messengers` | Массив мессенджеров; при пустом массиве блок скрыт | `[]` |
| `socialLinks` | Массив соцсетей для футера; при пустом массиве скрыт | `[]` |

Примеры:

```js
messengers: [
  { name: "Telegram", url: "https://t.me/username", label: "Написать в Telegram" },
  { name: "WhatsApp", url: "https://wa.me/79000000000", label: "Написать в WhatsApp" }
],

socialLinks: [
  { name: "VK", url: "https://vk.com/clinic", label: "METE CLINIC во ВКонтакте" }
]
```

Поведение при пустых данных: телефонные ссылки удаляются, пустые строки контактов не рендерятся, карта и отзывы скрываются целиком, а не показываются пустыми рамками. Если не задан `bookingUrl`, все CTA ведут к блоку контактов и рядом с ними появляется пояснение, куда можно обратиться. Если не задан `maxUrl`, кнопки MAX в шапке и hero и строка мессенджера в контактах не рендерятся.

## Контент

В `content.js`:

- `services` — 4 направления: заголовок, описание, изображение, `alt`, необязательная отдельная ссылка;
- `prices` — 8 позиций: название, уточнение, цена;
- `team` — 4 специалиста: имя, должность, инициалы для монограммы, путь к фото, `profileUrl` на страницу мастера в Yclients.

Фото сотрудников не выдумываются. Пока `photo` пустой, показывается монограмма. Чтобы добавить фото:

1. положите файл в `assets/images/team/` (рекомендуется портрет 3:4, до 1200 px по длинной стороне, WebP или JPEG);
2. укажите путь: `photo: "assets/images/team/zhara.webp"`;
3. добавьте `alt`, если он нужен, — для фото сотрудника он формируется автоматически как «Фото: Имя».

Плейсхолдеры направлений и интерьера — SVG в `assets/images/`. Их можно заменить реальными фото, изменив путь в `content.js` (для карточек направлений) или в `index.html` (hero и интерьер). Hero-изображение декоративное, поэтому у него пустой `alt`.

Карточка специалиста целиком является ссылкой на его `profileUrl`; внизу карточки есть видимая подпись «Отзывы и профиль →». Внешние страницы открываются в новой вкладке с `rel="noopener noreferrer"`, вложенных ссылок внутри карточки нет.

## Запись в Yclients и профили специалистов

Все 8 кнопок записи на странице (шапка, мобильное меню, первый экран, два «Полный прайс», прайс, «О клинике», контакты) и 4 карточки направлений ведут на общую страницу записи из `bookingUrl`:

`https://n1801245.yclients.ru/company/1599669/personal/menu?o=`

Ссылка открывается в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`). Официального кода `widgetJS` Yclients в проекте нет, поэтому используется обычный переход на страницу записи; iframe-попап с внешней страницей не делается.

Четыре карточки специалистов ведут на их страницы в Yclients (URL хранятся в `content.js`, поле `profileUrl`), где посетитель может посмотреть профиль и отзывы. Карточки работают с клавиатуры, имеют hover/focus-состояния и не содержат вложенных ссылок.

MAX вынесен в отдельную настройку `maxUrl` и рендерится одной общей функцией в трёх местах: в шапке непосредственно перед телефоном, в hero сразу после телефона и в контактах под телефоном. В шапке и hero это прежняя круглая кнопка, но с монохромным логотипом MAX вместо текста; в контактах — строка «Мессенджер» со ссылкой «Написать нам», выровненная по сетке как «Телефон». В футере MAX больше нет. Логотип используется как CSS-маска и наследует цвет через `currentColor`, поэтому совпадает по стилю с телефонной иконкой и меняется на кремовый при hover. В шапке и hero сохраняются `aria-label`/`title` «Написать в MAX», в контактах — `aria-label` «Написать нам в MAX». Все ссылки открываются в новой вкладке с `rel="noopener noreferrer"`. На ширине меньше 360 px кнопка в шапке скрыта, чтобы не переполнять её; в hero и контактах MAX остаётся видимым.

## Карта

Используется официальный iframe-виджет 2ГИС, без API-ключей и без платных сервисов. Встраивается только `src`, не HTML-код. Карта заполняет адаптивный контейнер: 320 px на мобильном и доступную высоту карточки на широких экранах; iframe получает `sandbox` с разрешениями из кода встраивания. Если `mapEmbedUrl` пуст, карточка карты скрывается, а блок контактов становится одноколоночным.

Старая конфигурация Яндекс Карт сохранена закомментированной в `site-config.js` и может быть возвращена без восстановления URL. Ссылка «Открыть в Яндекс Картах» вместе с картой отключена. Ссылка «Открыть в 2ГИС» появится только после заполнения `twoGisUrl` прямой ссылкой на карточку организации; выдумывать её нельзя.

## Отзывы

Встроен официальный виджет отзывов Яндекс Карт. Рейтинг и тексты отзывов не хранятся в коде и не редактируются — они всегда актуальны на стороне Яндекса. Если виджет недоступен или `reviewsEmbedUrl` пуст, секция отзывов скрывается; ссылка на карточку удаляется, если не задан `reviewsUrl`.

## Доступность и поведение

- skip-link «Перейти к содержанию» с переходом фокуса на `<main tabindex="-1">`;
- видимый `:focus-visible` у ссылок и кнопок;
- мобильное меню: `aria-expanded`, блокировка прокрутки, закрытие по Esc и по клику на пункт, возврат фокуса на кнопку;
- поддержка `prefers-reduced-motion`;
- один `H1`, осмысленные `alt`, подписи у iframe, `loading="lazy"` у карты, отзывов и изображений ниже первого экрана;
- нет ссылок `href="#"`, `href=""` и пустых якорей;
- внешние ссылки открываются с `rel="noopener noreferrer"`.

## Ограничения

- Нет форм, бэкенда, онлайн-оплаты, аналитики и cookie-баннера.
- Запись возможна только через Yclients (заполнен `bookingUrl`), телефон или мессенджер; все CTA открывают Yclients в новой вкладке, без popup-виджета.
- Содержимое страниц Yclients и профиля MAX не проверялось — проверен только HTTP-статус ссылок.
- Карта — внешний iframe 2ГИС, отзывы — внешний виджет Яндекс Карт: нужен интернет, внутри виджетов возможна реклама.
- Шрифты системные (Constantia/Georgia и системный sans-serif), веб-шрифты не загружаются.
- Реальные фотографии в проект не добавлялись: используются только логотип и абстрактные SVG-плейсхолдеры.
