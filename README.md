# MÉTE CLINIC — WordPress

Перенос утверждённого статического сайта клиники MÉTE CLINIC на WordPress:
собственная тема `mete-clinic` и плагин управления контентом `mete-clinic-content`.

Дизайн, палитра, типографика, состав секций, каталог, карточки услуг и
специалистов, контакты, ссылки MAX и Yclients, карта 2ГИС — сохранены.
Исходный статический проект не изменялся.

```
mete-clinic-wp/
├─ mete-clinic-theme/          тема WordPress
├─ mete-clinic-content/        плагин управления контентом
├─ build-zips.ps1              сборка архивов + копирование логотипов + php -l
├─ build-zips.cmd              запуск сборки двойным кликом
├─ README.md                   этот файл
├─ tests/
│  ├─ service-checks.php       интеграционные проверки услуг (wp eval-file)
│  ├─ price-checks.php         интеграционные проверки импорта прайса
│  ├─ sheets-test.php          автономные проверки CSV/XLSX (без WordPress)
│  ├─ run-checks.php           браузерный запуск проверок без SSH
│  └─ lib/wordpress-stubs.php  заглушки функций WordPress для sheets-test.php
├─ tools/
│  └─ php-lint.js              проверка синтаксиса PHP без PHP CLI
└─ docs/
   ├─ verification.md          что проверено и что осталось проверить на хостинге
   ├─ content-map.md           соответствие исходных данных и записей WordPress
   └─ design-review.md         разбор дизайна и вёрстки
```

## 1. Требования

| Компонент | Версия |
| --- | --- |
| WordPress | 6.0+ (проверялось на структуре 6.x) |
| PHP | 7.4+ (совместимо с 8.1/8.2) |
| MySQL / MariaDB | любая поддерживаемая WordPress |
| Плагины | не требуются, платных зависимостей нет |

Тема и плагин не используют внешние CDN, сборщики и npm. Все стили и скрипты —
локальные файлы.

## 2. Сборка архивов

Оба архива создаёт скрипт (он же докопирует фирменные логотипы и проверит
синтаксис PHP, если в системе есть `php`). Достаточно двойного клика по
`build-zips.cmd` или команды:

```powershell
cd C:\Users\nyakovlev\.opencode\mete-clinic-wp
powershell -ExecutionPolicy Bypass -File .\build-zips.ps1
```

Результат в корне проекта:

* `mete-clinic-theme.zip`
* `mete-clinic-content.zip`

Скрипт:

1. копирует `mete-clinic-emblem.*` и `mete-clinic-logo-full.*` из
   `..\mete-clinic-demo-main\assets` в `mete-clinic-theme\assets\brand`,
   favicon и иконки — в `mete-clinic-theme\assets\icons`;
2. запускает `php -l` по всем PHP-файлам темы и плагина;
3. пакует **содержимое** папок, поэтому внутри архива лежат `style.css`,
   `functions.php`, `mete-clinic-content.php` и остальные файлы без лишней
   внешней папки;
4. проверяет, что в архиве нет вложенной папки проекта, и печатает отчёт.

Параметры: `-Source <путь>` — другая папка исходного сайта,
`-SkipLint` — не запускать `php -l`.

> `build-zips.ps1` намеренно написан в ASCII. Windows PowerShell 5.1 читает
> `.ps1` без BOM как системную ANSI-кодировку, и кириллица в скрипте ломает
> разбор строк. Если будете править скрипт и добавлять русский текст —
> сохраняйте файл как «UTF-8 с BOM».

> Важно: растровые логотипы (PNG/WEBP) — двоичные файлы, они не хранятся в
> репозитории темы, а копируются скриптом. Если тема установлена без сборки,
> в шапке будет текстовый знак «M», а в подвале — название сайта. Для
> полноценного логотипа либо запустите `build-zips.ps1`, либо загрузите
> эмблему через «Внешний вид → Настроить → Свойства сайта → Логотип».

## 3. Установка на тестовый WordPress (Timeweb)

Порядок важен: сначала плагин, затем тема.

### 3.1. Плагин

1. «Плагины → Добавить новый → Загрузить плагин».
2. Выберите `mete-clinic-content.zip`, нажмите «Установить», затем
   «Активировать».
3. При активации плагин создаёт:
   * 4 категории услуг;
   * 8 услуг из утверждённого прайса;
   * 4 специалистов с подтверждёнными ФИО, специализацией и ссылками Yclients.

Повторная активация не создаёт дубликатов: записи ищутся по точному названию.

### 3.2. Тема

1. «Внешний вид → Темы → Добавить новую → Загрузить тему».
2. Выберите `mete-clinic-theme.zip`, установите и активируйте.

### 3.3. После установки

1. «Настройки → Постоянные ссылки» → выбрать «Название записи» → «Сохранить».
   Это нужно, чтобы заработали адреса `/uslugi/` и `/specialisty/`.
2. «Настройки → Общие»: название сайта `MÉTE CLINIC`, краткое описание
   `Клиника эпиляции и косметологии`.
3. «Внешний вид → Настроить → Свойства сайта → Значок сайта» — favicon из
   `assets/icons/favicon-512.png` исходного проекта (или из архива темы).
4. «MÉTE CLINIC → Настройки сайта» — проверить телефон, адрес, ссылку записи.
5. Меню: если нужен собственный набор пунктов, создайте меню в
   «Внешний вид → Меню» и назначьте его на «Основная навигация». Без меню
   выводится встроенный набор: Услуги, Каталог, Специалисты, О клинике, Контакты.

## 4. Как устроен контент

### Услуги (`mete_service`)

Меню «MÉTE CLINIC → Услуги».

| Поле в админке | Где в WordPress | Назначение |
| --- | --- | --- |
| Название | заголовок записи | заголовок карточки |
| Категория | блок «Категории» | направление, по нему строится фильтр каталога |
| Краткое описание | «Отрывок» | подпись под названием в прайсе и каталоге |
| Полное описание | основной редактор | страница услуги |
| Тип цены | блок «Параметры услуги» | фиксированная, «от», диапазон |
| Цена / цена «до» | там же | вывод: `2 290 ₽`, `от 2 500 ₽`, `2 000 – 3 500 ₽` |
| Продолжительность | там же | целое число минут, 1–1440; вывод `60 мин` |
| Изображение | «Изображение записи» | карточка и страница услуги |
| Статус публикации | «Опубликовано» / «Черновик» | черновики не выводятся нигде |
| Показывать на главной | флаг | попадание в блок «Популярные услуги» |
| Порядок на главной | число | меньше — выше |
| Ссылка записи в Yclients | URL | если пусто, берётся общая ссылка из настроек |
| ID услуги Yclients | строка | задел на будущую интеграцию, нигде не выводится |

Удаление — стандартной корзиной WordPress.

**Как устроена форма.** Блок «Категория услуги» закреплён сверху правой
колонки: это штатный список категорий с чекбоксами и ссылкой «Добавить новую
категорию». Блок «Параметры услуги» показывает только нужные поля цены:

* «Фиксированная» — одно поле;
* «От» — одно поле, на сайте выводится `от 2 500 ₽`;
* «Диапазон» — два поля, второе появляется только для этого типа.

Ошибки не теряются молча: если цена, продолжительность, ссылка записи или
ID Yclients не проходят проверку, после сохранения выводится предупреждение,
а уже сохранённое значение остаётся. Цена `0` считается незаданной — на сайте
не появляется `0 ₽`.

### Список услуг

«MÉTE CLINIC → Услуги» — штатный список записей WordPress с доработками:

* фильтр над таблицей: все услуги, без цены, без категории, без описания,
  «На главной», «Со своей ссылкой записи»; категория выбирается отдельным
  списком;
* сортировка по цене и по порядку на главной — клик по заголовку колонки;
* «Быстрое редактирование»: тип цены, цена, вторая цена, минуты, флаг и порядок
  на главной — без открытия полной формы;
* массовые действия: «Показать на главной», «Убрать с главной», «Изменить
  категорию на…»;
* «Дублировать» в строке создаёт копию услуги в черновике;
* колонка «Описание» показывает, заполнено ли полное описание, а строка
  предупреждения подсказывает, чего не хватает карточке.

Порядок на главной меняется перетаскиванием: в списке с фильтром «На главной»
у строк появляется ручка, порядок сохраняется сразу после отпускания. В обычном
списке перетаскивания нет — там порядок задаётся числом.

Список специалистов устроен так же: перетаскивание меняет «Порядок отображения»,
а колонка «Запись» показывает, задана ли личная ссылка Yclients.

### Категории услуг (`mete_service_cat`)

Меню «MÉTE CLINIC → Категории услуг».

* Название — заголовок карточки направления на главной.
* Описание — текст под заголовком.
* «Порядок категории» (число) — порядок карточек на главной.
* «Изображение категории» — ID файла из «Медиафайлов». Если пусто,
  используется встроенная иллюстрация направления (лазер, лицо, тело,
  инъекции) по слагу категории.

Оба поля редактируются на стандартных экранах «Добавить категорию» и
«Изменить категорию», а в списке категорий появились колонки «Порядок» и
«Изображение». Удаление категории не удаляет услуги: записи остаются, но
перестают попадать в её фильтр.

Категории без опубликованных услуг на главной не показываются; в фильтре
каталога категория появляется автоматически, как только к ней отнесена
хотя бы одна опубликованная услуга.

### Специалисты (`mete_specialist`)

Меню «MÉTE CLINIC → Специалисты».

| Поле | Где | Примечание |
| --- | --- | --- |
| ФИО | заголовок | на карточке выводится полностью |
| Фотография | «Изображение записи» | без фото показывается монограмма из инициалов |
| Специализация | блок «Данные специалиста» | например, «Косметолог» |
| Образование и квалификация | там же | только подтверждённые данные |
| Опыт работы | там же | только подтверждённые данные |
| Описание | основной редактор | страница специалиста |
| Ссылка записи в Yclients | там же | профиль специалиста; карточка целиком становится ссылкой |
| ID сотрудника Yclients | там же | задел на интеграцию |
| Порядок отображения | блок «Атрибуты» | меньше — раньше |
| Активность | статус записи | «Черновик» скрывает специалиста со всех страниц |

**Образование и опыт не заполнены намеренно:** в исходном проекте таких данных
нет, придумывать их нельзя. Поля пустые, пока клиника не передаст сведения.

### Настройки сайта

«MÉTE CLINIC → Настройки» — четыре вкладки, все поля на одной форме:

* **Контакты** — телефон (как показывать), номер для `tel:`, адрес, график
  работы (пусто → строка скрыта);
* **Запись и мессенджеры** — основная ссылка записи Yclients, ссылка MAX,
  другие мессенджеры (по одному в строке, формат `Название | https://ссылка`);
* **Карта** — URL карты 2ГИС (только `src` iframe, не HTML) и ссылка на карточку
  в 2ГИС;
* **Отзывы** — заголовок, текст, URL официального виджета, ссылка на карточку,
  поле для кода виджета.

Номер для `tel:` подставляется из телефона на лету: как только телефон изменён,
ссылка обновляется. Если номер вручную поправлен и отличается от телефона,
автоподстановка его не перезаписывает. После сохранения выводится уведомление
«Настройки сохранены.».

У каждой ссылки есть кнопка «Проверить»: сервер запрашивает адрес и показывает
код ответа или ошибку, не уводя со страницы. Проверяются только `http`/`https`
и только публичные адреса.

Все URL проверяются на `http`/`https`. Пустое поле означает «не выводить».

### Обзор

«MÉTE CLINIC → Обзор» — первый экран плагина: сколько услуг, категорий и
специалистов опубликовано; сколько услуг без цены, без категории, без описания
и со своей ссылкой записи; чек-лист «что заполнить» со ссылками на
отфильтрованные списки и быстрые переходы к остальным экранам.

Цифры не зашиты в код: они считаются по базе, поэтому после импорта или
редактирования меняются сами.

### Прайс (Excel)

«MÉTE CLINIC → Прайс (Excel)» — выгрузка и загрузка каталога таблицей.

* **Выгрузка.** Текущий прайс или пустой шаблон с примером строки — для услуг,
  специалистов и категорий, в XLSX (книга из трёх листов: «Услуги»,
  «Специалисты», «Категории») или в CSV.
* **Загрузка.** CSV или XLSX до 5 МБ. Режим выбирается при загрузке: «Только
  добавить новые» (по умолчанию), «Только обновить существующие», «Добавить и
  обновить».
* **Сопоставление.** Сначала по `ID`, затем по сохранённому ключу импорта
  (`md5(слаг|название)`), затем по названию; категория — по слагу или названию.
* **Предпросмотр.** До применения видно, что будет создано, что изменится
  (старое → новое) и какие строки не пройдут проверку — с номером строки и
  причиной.
* **Ничего не удаляется.** Пустая ячейка не стирает поле; очистка возможна
  только при явной галочке «Очищать поля пустыми ячейками».
* **Резервная копия.** Перед применением текущие данные сохраняются в
  `uploads/mcc-backups/`: файл со случайным именем, каталог закрыт от листинга.

CSV — UTF-8 с BOM и разделителем `;`, открывается в Excel двойным кликом.
XLSX читается и пишется встроенными средствами PHP (`ZipArchive` и
`SimpleXML`), без внешних библиотек. Если на хостинге нет расширения `zip`,
кнопки XLSX отключаются с подсказкой, а CSV продолжает работать.

### Инструменты

«MÉTE CLINIC → Инструменты»: повторный импорт каталога из `data/catalog.json`,
пересоздание страниц и меню, статистика каталога и путь к файлу данных.
Действия защищены nonce и доступны только администратору.

## 5. Главная страница

Состав (порядок сохранён с исходного сайта):

1. Первый экран — заголовок, кнопки записи, телефон, MAX, преимущества.
2. «Наши услуги» — 4 карточки направлений из категорий.
3. «Прайс — ключевые позиции» — только опубликованные услуги с флагом
   «Показывать на главной», отсортированные по «Порядку на главной».
4. «Наши специалисты» — опубликованные специалисты по «Порядку отображения».
5. «Отзывы» — выводится только если заполнен URL виджета или код виджета.
6. «О клинике».
7. «Контакты» — контакты, мессенджеры, карта 2ГИС.

Тексты первого экрана и блока «О клинике» — часть шаблона
(`template-parts/hero.php`, `template-parts/about.php`). Они не являются
данными каталога и не дублируют услуги.

## 6. Каталог

Адрес: `/uslugi/` (архив типа записей). Ссылки «Полный каталог» и «Полный прайс»
ведут туда.

* Выводятся все опубликованные услуги, независимо от флага «на главной».
* Фильтр по категориям строится автоматически из таксономии, с количеством
  услуг; состояние хранится в параметре `?mete_cat=<slug>` и работает без JS.
* У каждой услуги своя кнопка «Записаться»: ссылка услуги, иначе общая ссылка
  записи, иначе переход к блоку контактов.
* Мобильная вёрстка: карточка в одну колонку, кнопка записи на всю ширину.
  Фильтры на ширине до 559 px — одна горизонтальная лента с прокруткой,
  чипы не переносятся и не растягивают страницу. Длинные названия и цены
  переносятся внутри карточки, страница не получает горизонтальную прокрутку
  на 320, 375, 430, 768 и 1440 px.
* Услуги в PHP-шаблонах не перечислены — только запросы к базе.

Страница специалистов: `/specialisty/` и карточки `/specialisty/<slug>/`.
Страница услуги: `/uslugi/<slug>/`.

## 7. Yclients и 2ГИС

### Yclients

Автоматической интеграции через API нет — как и требовалось. Используются
обычные ссылки:

* общая ссылка записи — в настройках сайта;
* индивидуальная ссылка услуги — в поле услуги (необязательно);
* профиль специалиста — в поле специалиста.

Все внешние ссылки открываются в новой вкладке с `rel="noopener noreferrer"`.
Идентификаторы Yclients (`ID услуги`, `ID сотрудника`) сохраняются, но нигде не
выводятся — это задел под будущую интеграцию.

### 2ГИС

* В настройках есть поле «URL карты (src iframe)» — в него вставляется **только
  адрес** из официального кода встраивания. HTML-код карты не принимается.
* Ссылка «Открыть в 2ГИС» появляется только после заполнения поля
  «Ссылка на карточку в 2ГИС».
* Блок отзывов: предпочтительно поле «URL официального виджета (src iframe)».
  Поле «Код официального виджета» предназначено для официального кода, если он
  будет передан; код принимается только от администратора с правом
  `unfiltered_html` и выводится как есть. Парсинга отзывов нет.
* Ссылка и код виджета 2ГИС не выдумывались: по умолчанию оба поля пустые,
  блок отзывов скрыт.

## 8. Пустые поля и отсутствие изображений

| Ситуация | Поведение |
| --- | --- |
| Нет цены | в каталоге «Цена по запросу», в прайсе «—» |
| Нет изображения услуги/специалиста | бежевая подложка или монограмма из инициалов |
| Нет фотографии ни у одного специалиста | выводится прежняя подпись «Фотографии появятся…» |
| Нет телефона | телефонные ссылки не рендерятся |
| Нет MAX | кнопки MAX не рендерятся |
| Нет карты | карточка карты скрыта, контакты в одну колонку |
| Нет отзывов | секция отзывов не выводится |
| Нет общей ссылки записи | все кнопки ведут к блоку контактов и появляется пояснение |
| Нет услуг с флагом «на главной» | блок прайса на главной не выводится |
| Плагин не активирован | секции данных скрыты, администратору показывается предупреждение |

## 9. Безопасность

* Мета-поля: nonce на каждую форму (`wp_nonce_field` / `wp_verify_nonce`),
  проверка `current_user_can( 'edit_post', $post_id )`, пропуск автосохранения
  и ревизий.
* Настройки: `settings_fields()` + `register_setting` с `sanitize_callback`,
  страница доступна только `manage_options`.
* Валидация: URL — только `http`/`https` с хостом; цена — неотрицательное число
  с заменой запятой; ID — `[A-Za-z0-9_-]`; порядок — целое 0…9999;
  текст — `sanitize_text_field` / `sanitize_textarea_field`.
* Вывод: `esc_html`, `esc_attr`, `esc_url`, `esc_textarea`; описания —
  через стандартный редактор WordPress.
* Код виджета принимается только от пользователей с `unfiltered_html`;
  для остальных очищается `wp_kses_post`.
* Секретов в коде нет: ключи API не используются.
* Прямой доступ к файлам закрыт проверкой `ABSPATH` / `WP_UNINSTALL_PLUGIN`.

## 11. Известные ограничения

* Нет автоматической интеграции с Yclients API (по требованию).
* Нет онлайн-оплаты, форм обратной связи, аналитики и cookie-баннера.
* Комментарии к услугам и специалистам не используются.
* Шрифты системные (`Constantia`/`Georgia` и системный sans-serif), веб-шрифты
  не загружаются.
* Реальные фотографии специалистов и интерьера не добавлялись — используются
  утверждённые SVG-иллюстрации и монограммы.
* Скриншот темы (`screenshot.png`) не приложен: файл двоичный и в репозитории
  отсутствует. На работу темы это не влияет.
* Удаление плагина не удаляет услуги и специалистов — данные клиники
  сохраняются; удаляются только настройки и флаг импорта.
* Тема рассчитана на классические шаблоны; блочный редактор используется только
  для содержимого записей и страниц.
* XLSX требует расширения PHP `zip` и `SimpleXML`. Без них остаётся CSV —
  форматы равнозначны по составу колонок.
* Импорт меняет только поля каталога: цены, описания, категории, порядок.
  Произвольные поля, SEO-плагины и вложения он не трогает и ничего не удаляет.
* Перетаскивание порядка услуг доступно только в списке с фильтром
  «На главной»; в остальных списках порядок задаётся числом.
* Проверка ссылки — серверный запрос: при медленном ответе кнопка может
  показывать «Проверяем…» несколько секунд.

## 12. Откат

1. Активировать стандартную тему — контент останется в базе.
2. Деактивировать плагин — записи останутся, но перестанут выводиться.
3. Полное удаление данных — только вручную через админку или базу.

Домен, DNS и настройки хостинга не изменялись.

* Поле «Порядок категории» узкое в формах добавления и редактирования
