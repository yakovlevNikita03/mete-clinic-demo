## C. Что НЕ проверено и почему

| Проверка | Причина |
| --- | --- |
| `php -l` по всем файлам | в системе сборки нет PHP CLI. Команда включена в `build-zips.ps1`: если `php` найден, синтаксис проверяется, и при ошибке архивы не создаются |

| Изменение порядка популярных услуг | требует работающего WordPress |
| Вывод каталога и фильтров | требует работающего WordPress |
| Адаптивность в браузере | требует запущенного сайта; вёрстка перенесена с утверждённого лендинга и дополнена правилами для каталога |
| Карта 2ГИС и виджет отзывов | внешние сервисы, нужен реальный домен и интернет |

### G1. Автоматический скрипт

Скрипт проверяет: регистрацию типа и таксономии, создание категории и услуги,
фиксированную цену, «от», диапазон, диапазон с максимумом меньше минимума,
пустую цену, минуты, попадание в популярные, порядок популярных, снятие флага
и фильтр каталога. Созданные записи удаляются в конце.

**Способ 1 — SSH + WP-CLI.**

```bash
cd ~/domains/example.ru/public_html
php wp-cli.phar --user=admin eval-file service-checks.php 2>&1 | tee service-checks.log
```

**Способ 2 — браузер, без SSH.**

1. Загрузить `tests/run-checks.php` и `tests/service-checks.php` в корень
   WordPress (рядом с `wp-load.php`).
2. Войти в админку под администратором.
3. Открыть `https://example.ru/run-checks.php`.
4. Скопировать вывод.
5. Удалить оба файла с сервера.

**Не запускался:** в среде переноса нет PHP CLI и WordPress. Запустить на
тестовом сайте Timeweb и сохранить вывод.

### G4. Адаптивность каталога

Проверять `/uslugi/` в инструментах разработчика на ширинах **320, 375, 430,
768, 1440**. На каждой:

* `document.documentElement.scrollWidth` не больше `clientWidth` — страница не
  прокручивается вбок;
* названия услуг и цены не выходят за границы карточки;
* чипы категорий не выходят за экран: до 559 px это лента с горизонтальной
  прокруткой, сама страница при этом не двигается;
* кнопка «Записаться» не меньше 44 px по высоте и доступна пальцем;
* на 320–430 px карточка в одну колонку, цена читается, кнопка на всю ширину;
* на 768 px карточка «изображение + текст», на 1440 px — три колонки.
