Услуги, специалисты и настройки сайта клиники MÉTE CLINIC.

== Description ==

Плагин регистрирует типы записей «Услуги» и «Специалисты», таксономию
«Категории услуг» и страницу настроек сайта. Данные не зависят от активной
темы и переживают её смену.

Разделы меню «MÉTE CLINIC»:

* Настройки сайта — телефон, адрес, график, MAX и мессенджеры, ссылка записи
  Yclients, карта 2ГИС, блок отзывов.
* Услуги — каталог с ценой, типом цены, продолжительностью, изображением,
  флагом «Показывать на главной», порядком на главной и ссылкой записи.
* Категории услуг — направления, выводятся на главной автоматически.
* Специалисты — ФИО, фотография, специализация, образование, опыт, описание,
  ссылка записи, порядок и статус.

== Installation ==

1. Загрузите папку плагина в `/wp-content/plugins/` или установите ZIP через
   «Плагины → Добавить новый → Загрузить плагин».
2. Активируйте плагин. При активации создаются категории, восемь услуг и
   четыре специалиста из утверждённого прайса.
3. Откройте «MÉTE CLINIC → Настройки сайта» и подтвердите контакты.

== Changelog ==

= 1.3.0 =
* Меню плагина разбито на подпункты: «Обзор», «Услуги», «Категории услуг»,
  «Специалисты», «Прайс (Excel)», «Настройки», «Инструменты».
* Новый экран «Обзор»: счётчики каталога, чек-лист «что заполнить» и ссылки на
  отфильтрованные списки. Цифры считаются по базе, а не заданы в коде.
* Список услуг: фильтры (без цены, без категории, без описания, «На главной»,
  своя ссылка записи), фильтр по категории, сортировка по цене и порядку,
  быстрое редактирование, массовые действия (показать/убрать с главной,
  сменить категорию), дублирование услуги.
* Перетаскивание порядка: специалисты — «Порядок отображения», услуги —
  «Порядок на главной» в отфильтрованном списке.
* Экран «Прайс (Excel)»: выгрузка текущих данных и шаблонов, импорт CSV и XLSX
  для услуг, специалистов и категорий, предпросмотр изменений, отчёт об
  ошибках по строкам, резервная копия перед применением.
* Импорт не удаляет записи. Режимы: «только добавить новые» (по умолчанию),
  «только обновить существующие», «добавить и обновить». Пустая ячейка не
  стирает поле без отдельной галочки.
* Настройки разделены на вкладки «Контакты», «Запись и мессенджеры», «Карта»,
  «Отзывы». Номер для `tel:` подставляется из телефона, если не задан вручную.
  Ссылки можно проверить кнопкой «Проверить» без перехода на сайт.
* «Инструменты»: повторный импорт каталога, пересоздание страниц и меню,
  статистика.
* CSV — UTF-8 с BOM и разделителем `;`. XLSX собирается встроенными средствами
  PHP (`ZipArchive`, `SimpleXML`); без расширения `zip` остаётся только CSV.
